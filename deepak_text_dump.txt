[71] ABSTRACT
[73] Network traffic is continuously increasing due to the growing use of cloud services, online applications, video streaming, and digital communication. Efficient network capacity planning is therefore important to prevent congestion and maintain reliable network performance. This project, “Network Capacity Forecasting with Peak Quantiles and Congestion Change-Point Detection,” focuses on analyzing historical network traffic data to forecast future capacity requirements and identify significant changes in traffic patterns.
[74] The proposed system uses data preprocessing, statistical analysis, peak quantile estimation, and change-point detection techniques to analyze network behavior. Peak quantiles are used to understand high-traffic conditions beyond average network usage, while change-point detection identifies sudden or significant changes that may indicate congestion or changing traffic patterns. Data visualization is also used to present traffic trends and detected congestion periods clearly.
[75] The project provides a data-driven approach for proactive network capacity planning. By identifying peak demand and changes in traffic behavior, network administrators can better understand future capacity requirements, optimize available resources, and reduce the possibility of network overload. The system demonstrates how statistical and data analytics techniques can be applied to improve network monitoring and capacity management.
[77] With the rapid growth of cloud computing, online services, IoT devices, video streaming, and digital communication, network traffic is increasing continuously. These changes may indicate the beginning of unusual traffic conditions or potential congestion. By detecting such changes, network administrators can monitor network behavior more effectively and take preventive actions.

The results can support proactive capacity planning, better resource utilization, and early identification of possible congestion. [141] HAPTER 1 INTRODUCTION
[144] In Today’s digital world, network infrastructure plays an important role in supporting applications such as cloud computing, online services, video streaming, communication systems, and data-intensive applications. As the number of users and the amount of data traffic continue to increase, network traffic can experience significant fluctuations during different time periods. If network capacity is not planned properly, high traffic can result in congestion, increased latency, packet loss, and reduced service quality. Therefore, accurate network capacity forecasting is essential for maintaining reliable and efficient network performance.
[145] Network Capacity Forecasting with Peak Quantiles and Congestion Change-Point Detection is a data-driven project designed to analyze historical network traffic and estimate future capacity requirements. Instead of relying only on average traffic values, the project focuses on peak traffic behavior using quantile-based analysis. Peak quantiles help identify high-demand traffic levels and provide a more reliable basis for capacity planning. This approach can help network administrators understand how much capacity may be required during periods of unusually high traffic.
[146] The project also incorporates congestion change-point detection to identify significant changes in network traffic patterns. A change point represents a point in time where the statistical behavior of the network changes, such as a sudden increase or decrease in traffic. Detecting these changes can help identify emerging congestion conditions and understand unusual network behavior.
[147] The system uses historical network metrics, data preprocessing, statistical analysis, forecasting techniques, and visualization to study traffic patterns. By combining peak quantile analysis with change-point detection, the project provides a systematic approach to understanding network demand and identifying periods that may require additional capacity.
[148] The main objective of this project is to support proactive network management by providing useful insights into future traffic requirements and possible congestion periods. The results can assist network administrators in making data-driven capacity planning decisions, improving resource utilization, reducing the risk of network overload, and maintaining better network performance. Overall, the project demonstrates how data analytics and statistical techniques can be applied to real-world network capacity planning and congestion monitoring.
